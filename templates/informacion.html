01

Introducción

La realidad virtual y los entornos digitales interactivos ofrecen nuevas formas de presentar y explorar espacios mediante herramientas tecnológicas. Estas soluciones permiten organizar información visual y proporcionar experiencias de navegación accesibles desde una aplicación.

El presente proyecto consiste en desarrollar una aplicación de recorrido virtual que permita al usuario seleccionar y explorar diferentes recorridos mediante una interfaz gráfica y una escena tridimensional. A través de fotografías organizadas por recorrido, el usuario podrá visualizar los espacios y desplazarse entre las imágenes mediante controles interactivos.

El sistema se organiza en diferentes pantallas: un menú principal, una sección informativa, un selector de recorridos y una pantalla destinada a la experiencia virtual. Esta separación busca facilitar la navegación, mantener una estructura organizada y permitir futuras mejoras en la aplicación.

El desarrollo integra tecnologías web para construir la interfaz, controlar las interacciones y representar el entorno tridimensional. Asimismo, el proyecto representa una oportunidad para aplicar conocimientos de programación, diseño de interfaces y administración de proyectos de software.

02

Objetivo general

Diseñar y desarrollar una aplicación de recorrido virtual que permita explorar diferentes espacios mediante fotografías y una escena tridimensional interactiva, proporcionando una interfaz intuitiva para seleccionar recorridos y navegar por su contenido.

03

Objetivos específicos

  • Diseñar un menú principal que facilite el acceso a las funciones de la aplicación.
  • Crear una sección informativa que presente el propósito y las características del proyecto.
  • Organizar los contenidos visuales en recorridos independientes.
  • Implementar controles para avanzar y retroceder entre las fotografías.
  • Integrar una escena tridimensional mediante tecnologías de realidad virtual para navegador.
  • Mantener una estructura modular que facilite el mantenimiento y la ampliación del sistema.
04

Funcionamiento de la aplicación

01

Menú principal

Presenta las opciones para iniciar la experiencia o consultar la información del proyecto.

02

Selección del recorrido

Permite elegir el recorrido que el usuario desea explorar.

03

Experiencia virtual

Presenta el contenido fotográfico dentro de un entorno tridimensional.

04

Navegación interactiva

Ofrece controles para cambiar de imagen y continuar explorando el recorrido.

05

Tecnologías utilizadas

HTML5

Define la estructura de las páginas y sus componentes.

CSS3

Establece la apariencia visual, la distribución y la adaptación a diferentes pantallas.

JavaScript

Controla las interacciones, los botones y la navegación entre pantallas.

A-Frame

Permite construir escenas tridimensionales y experiencias inmersivas desde el navegador.
